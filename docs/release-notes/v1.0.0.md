# LyricHub 1.0.0

The first public release (2026-10-26).

LyricHub is a Windows overlay that shows the current Spotify song with karaoke-style lyrics over games, in sync with what you hear. It reads the song from the Windows media session, so it needs no Spotify login and no Spotify API.

## Features

- Synced lyrics from [LRCLIB](https://lrclib.net) with a karaoke fill that moves word by word, plus cover, title and artist.
- Four layouts (Karaoke, Bar, Stack, Minimal) and five themes, with an accent colour taken from the album cover.
- Edit mode right on the screen: drag the overlay, scale it at the corners, change the width at the sides.
- Stays on top of games, even ones that push themselves to the front, and never takes the focus: the game keeps mouse and keyboard. It can be limited to fullscreen apps.
- Sync corrections per song (Ctrl+Alt+, and Ctrl+Alt+.), an offset per output device, a calibration assistant and the Sync Lab.
- Japanese lines in romaji (Ctrl+Alt+R).
- Hotkeys you can change or turn off: overlay on/off (Ctrl+Alt+L), edit mode (Ctrl+Alt+E), layout (Ctrl+Alt+K).
- German and English interface, tray icon, optional autostart, lyrics cached locally.

## Requirements

- Windows 11, or Windows 10 version 2004 or later (tested on Windows 11), 64-bit
- The Spotify desktop app (Microsoft Store or spotify.com); the web player is not supported
- Microsoft Edge WebView2 Runtime: part of Windows 11; if it is missing, the installer fetches it
- Internet access for the lyrics lookup

## Installation

1. Download `LyricHub_1.0.0_x64-setup.exe` from the assets of this release and run it.
2. The installer sets LyricHub up for the current user only and needs no administrator rights.
3. The installer is not code-signed, so Windows SmartScreen reports an unknown publisher. Choose "More info" → "Run anyway".
4. Start Spotify and play a song. LyricHub sits in the tray and shows the overlay.

To uninstall, use Windows Settings → Apps → LyricHub.

SHA-256 of `LyricHub_1.0.0_x64-setup.exe`:

```
1a8604cf0b8946af905948a5688ef0324a304b8e4b2e1a1a4bb6e6c11db86d55
```

Check it in PowerShell with `Get-FileHash .\LyricHub_1.0.0_x64-setup.exe -Algorithm SHA256`.

## Known limitations

- Games in exclusive fullscreen can hide the overlay; use the borderless window mode where a game offers it.
- Lyrics depend on LRCLIB. A direct hit takes about 0.1 s; when LRCLIB is slow or has to search, it can take 1.5–2.3 s.
- Waking up from sleep was not tested live.
