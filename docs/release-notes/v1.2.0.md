# LyricHub 1.2.0

Plugins, and the first one: real word times from the sound (2026-10-29).

## What's new

- **Plugins.** Under Settings → Plugins, LyricHub installs plugins from a ZIP file. Before anything is written it shows name, version, permissions and the file's SHA-256. Plugins can be switched on and off, and the page shows their state.
  - Plugins run as separate programs at "below normal" priority. A crashing plugin does not take LyricHub down, and plugins end with LyricHub.
  - For now there are only LyricHub's own plugins.
- **Align: real word times (separate download, optional).** LRCLIB almost only has line times, so LyricHub estimates when each word is sung. The plugin Align measures it instead:
  - On the first listen it captures the player's sound. After the song it aligns the lyrics to the singing.
  - From the second listen on, the words light up with the singing, with the word glow.
  - It computes only while no game or other program runs fullscreen in front, with 2 cores at "below normal" priority. That takes about 1 to 1.5 times the song length and up to 1.5 GB of memory; idle it takes about 30 MB.
  - The sound stays in memory and is dropped after the alignment. Only the word times are stored.
  - On first start it downloads a 588 MB model (MIT) from huggingface.co.
  - Measured on songs with hand-aligned word times, the word starts are 37 ms off in the median, the estimate 129 ms ([P0 measurement](https://github.com/HeiligerHoly/LyricHub/blob/v1.2.0/docs/en/spike-align.md), [plugin report](https://github.com/HeiligerHoly/LyricHub/blob/v1.2.0/docs/en/plugin-align.md)).
  - How to install it, and what it does with your sound, is in the [plugin guide](https://github.com/HeiligerHoly/LyricHub/blob/v1.2.0/docs/en/plugins.md).
- **Diagnostics shows where a song's word times come from:** estimated, from the LRC file, or from a plugin.
- **Fixed:** With real word times, words sung earlier in a line lit up again every few seconds, and a dark smudge could show at the end of a line.

The full list is in the [changelog](https://github.com/HeiligerHoly/LyricHub/blob/v1.2.0/CHANGELOG.md).

## Requirements

- Windows 11, 64-bit (tested); Windows 10 from version 2004 is not tested
- The Spotify desktop app (Microsoft Store or spotify.com), or experimentally a browser
- Microsoft Edge WebView2 Runtime: part of Windows 11; if it is missing, the installer fetches it
- Internet access for the lyrics lookup
- For Align: about 620 MB of free disk space, and internet access once for the model

## Installation

1. Download `LyricHub_1.2.0_x64-setup.exe` from the assets of this release and run it. You can install it over an older version; settings, offsets and cached lyrics live in your user profile and stay.
2. The installer sets LyricHub up for the current user only and needs no administrator rights.
3. The installer is not code-signed, so Windows SmartScreen reports an unknown publisher. Choose "More info" → "Run anyway".
4. Optional: download `lyrichub-align-0.1.0.zip`, do not unpack it, and choose it in LyricHub under Settings → Plugins → "Install plugin from ZIP …". Check that the SHA-256 shown matches the one below, install, and switch the plugin on.

SHA-256 of `LyricHub_1.2.0_x64-setup.exe`:

```
d1bbd4eb1efd460ddaed356873c6555b93dd32c6f76f448040db531ae444ced4
```

SHA-256 of `lyrichub-align-0.1.0.zip`:

```
39c2e124cc67134d70c174934928f1f691fc0ad5894303b7df6a7c16952d8aef
```

Check them in PowerShell with `Get-FileHash .\LyricHub_1.2.0_x64-setup.exe -Algorithm SHA256`.

Both files were rebuilt on 2026-10-29, a few hours after the release, from the same code: the first builds contained the build PC's user folder in the source paths Rust embeds for error messages. Files downloaded before that have the SHA-256 `63994c62…7bdbc` (installer) and `f32cb845…a06a3` (ZIP) and work the same.
