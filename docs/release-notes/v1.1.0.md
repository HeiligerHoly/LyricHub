# LyricHub 1.1.0

Browser support, more accurate word timing, and a switch for the word fill (2026-10-28).

## What's new

- **Browsers as the player (experimental).** Under Settings → Behavior → Player, LyricHub can follow a browser instead of Spotify. The list shows the media sessions Windows knows, with what is playing, so a browser is easy to recognise.
  - YouTube Music works in Edge and Firefox-based browsers.
  - Regular YouTube and the Spotify web player work in Edge. Firefox-based browsers often report no time on regular YouTube.
  - YouTube titles such as "Artist - Song (Official Video)" from a VEVO or "Topic" channel are cleaned before the lookup.
  - Playback without a song length or artist counts as a video: no lyrics lookup, only the compact card. Video titles therefore do not go to LRCLIB.
  - Each player has its own offset under Settings → Sync, because a browser often plays the sound a little later than Spotify.
  - The measurements are in the [browser spike](https://github.com/HeiligerHoly/LyricHub/blob/v1.1.0/docs/en/spike-browser.md).
- **Word timing closer to the singing.** LRCLIB almost never has word times, so LyricHub estimates them. The estimate now uses syllables, holds the last word longer, and no longer stretches the words across the pause before the next line. Measured against 79 songs with hand-aligned word times, the median error of a word start fell from 184 to 136 ms, and the slowest tenth from 1.28 to 0.73 s ([report](https://github.com/HeiligerHoly/LyricHub/blob/v1.1.0/docs/en/word-timing.md)).
- **Switch for the word fill.** Under Settings → Appearance → "Fill word by word" the karaoke fill can be turned off. The current line then shows whole in the accent colour at once.
- **Fixed:** With themes that have an outline, the outline and shadows were cut off at the edges of each text line, most visibly on the first and last letter and above and below the title.

The full list is in the [changelog](https://github.com/HeiligerHoly/LyricHub/blob/v1.1.0/CHANGELOG.md).

## Requirements

- Windows 11, 64-bit (tested); Windows 10 from version 2004 is not tested
- The Spotify desktop app (Microsoft Store or spotify.com), or experimentally a browser (see above)
- Microsoft Edge WebView2 Runtime: part of Windows 11; if it is missing, the installer fetches it
- Internet access for the lyrics lookup

## Installation

1. Download `LyricHub_1.1.0_x64-setup.exe` from the assets of this release and run it. You can install it over an older version; settings, offsets and cached lyrics live in your user profile and stay.
2. The installer sets LyricHub up for the current user only and needs no administrator rights.
3. The installer is not code-signed, so Windows SmartScreen reports an unknown publisher. Choose "More info" → "Run anyway".

SHA-256 of `LyricHub_1.1.0_x64-setup.exe`:

```
04a94ea8df9a632bbfb783835bc929e24c13bbdc18e4ed08098a25107e36551e
```

Check it in PowerShell with `Get-FileHash .\LyricHub_1.1.0_x64-setup.exe -Algorithm SHA256`.
