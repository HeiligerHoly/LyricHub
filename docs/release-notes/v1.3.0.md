# LyricHub 1.3.0

More songs with lyrics, lines that start with the singing, more scripts, and LyricHub in games and streams (2026-10-31).

## What's new

- **Auto-Sync (in Align 0.2.0).** The timestamps on LRCLIB are set by hand and are often a few tenths of a second off. Once Align has heard a song, each line starts 150 ms before its first sung word, from the second listen on. Measured: line starts 38 ms from the sung first word in the median ([report](https://github.com/HeiligerHoly/LyricHub/blob/v1.3.0/docs/en/auto-sync.md)). On by default, a switch under Settings → Plugins → Align.
- **Recognize: lyrics for songs LRCLIB has no synced lyrics for (separate download, optional).** After the song it aligns LRCLIB's lyrics without timestamps to the singing, finds the song with a broader search that it checks against what it heard, or shows the text it recognized, marked "recognized". The lyrics show from the second listen on. Recognized text has errors, about every fifth word ([report](https://github.com/HeiligerHoly/LyricHub/blob/v1.3.0/docs/en/plugin-recognize.md)). It shares Align's model and its computing rules.
- **More songs with lyrics:**
  - Sped-up, slowed and Nightcore versions get the lyrics of the original, stretched to their length and marked "stretched".
  - Settings → Sync → "Pick other lyrics…" lists LRCLIB's entries for the song; your pick is kept.
  - Your own lyrics: "Own lyrics…" opens an editor for the current song, and `.lrc` files in `%APPDATA%\LyricHub\lrc` win over everything else. Without timestamps, Recognize aligns them after one listen.
  - A last search by the title alone finds songs whose artist LRCLIB spells differently.
- **Latin script for more languages.** The switch on the Overlay page (Ctrl+Alt+R) now also writes Korean, Chinese (pinyin), Cyrillic and Greek in Latin script, not only Japanese. "Original too" shows the original small below the converted line.
- **Games and streams:**
  - Its own place per game: in the edit mode (Ctrl+Alt+E), "Remember for <program> only" keeps place, size and layout for that program.
  - Gamepad buttons (Settings → Hotkeys, off by default): with a button held, Y shows or hides the overlay, X switches the layout, B the Latin script, the D-pad moves the lyrics by 100 ms.
  - A command line for Stream Deck or AutoHotkey: `lyrichub.exe --toggle`, `--edit`, `--layout`, `--romaji`, `--nudge -100`.
  - An OBS browser source (Settings → Overlay → Streaming, off by default), reachable only on this PC with a token, plus `now-playing.txt` with title and artist for a text source.
- **Smaller things:** the overlay dims during instrumental parts of 10 s or more; "Compute faster" lets Align and Recognize use half the processor cores (2 to 6) instead of 2.
- **Under the hood:** a crash of LyricHub leaves a report in its log folder, shown under Settings → Diagnostics and carried in the export, with song details and the Windows account name hidden. Plugins may commit at most 3 GB of memory. Lyrics from a plugin or without timestamps are checked against LRCLIB again after 14 days.
- **Fixed:** Align 0.1.0 (in 1.2.0) stopped measuring after its first idle minute until LyricHub restarted. Align 0.2.0 fixes that; please install it over the old version.

The full list is in the [changelog](https://github.com/HeiligerHoly/LyricHub/blob/v1.3.0/CHANGELOG.md).

## Requirements

- Windows 11, 64-bit (tested); Windows 10 from version 2004 is not tested
- The Spotify desktop app (Microsoft Store or spotify.com), or experimentally a browser
- Microsoft Edge WebView2 Runtime: part of Windows 11; if it is missing, the installer fetches it
- Internet access for the lyrics lookup
- For Align and Recognize: about 640 MB of free disk space for both (the model once, 588 MB), and internet access once for the model
- Recognize needs LyricHub 1.3.0

## Installation

1. Download `LyricHub_1.3.0_x64-setup.exe` from the assets of this release and run it. You can install it over an older version; settings, offsets and cached lyrics live in your user profile and stay.
2. The installer sets LyricHub up for the current user only and needs no administrator rights.
3. The installer is not code-signed, so Windows SmartScreen reports an unknown publisher. Choose "More info" → "Run anyway".
4. Optional: download `lyrichub-align-0.2.0.zip` and `lyrichub-recognize-0.1.0.zip`, do not unpack them, and choose each in LyricHub under Settings → Plugins → "Install plugin from ZIP …". Check that the SHA-256 shown matches the one below, install, and switch the plugin on. Align 0.2.0 installs over Align 0.1.0.

