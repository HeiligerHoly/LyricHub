# LyricHub 1.3.1

A fix for the Behavior page (2026-11-21).

## Fixed

- **Settings → Behavior showed only "500".** This happened while an app held several media sessions with the same id, as Elgato Studio does. The player list now names each app once, using its session that has a timeline or is playing.

Everything else is as in [1.3.0](https://github.com/HeiligerHoly/LyricHub/releases/tag/v1.3.0). The full list is in the [changelog](https://github.com/HeiligerHoly/LyricHub/blob/v1.3.1/CHANGELOG.md).

## Installation

1. Download `LyricHub_1.3.1_x64-setup.exe` from the assets of this release and run it. You can install it over an older version; settings, offsets, cached lyrics and installed plugins stay.
2. The installer sets LyricHub up for the current user only and needs no administrator rights.
3. The installer is not code-signed, so Windows SmartScreen reports an unknown publisher. Choose "More info" → "Run anyway".
4. The plugins have not changed: Align 0.2.0 and Recognize 0.1.0 are in the assets of [1.3.0](https://github.com/HeiligerHoly/LyricHub/releases/tag/v1.3.0).

SHA-256 of `LyricHub_1.3.1_x64-setup.exe`:

```
57681e2e8b777feb4f15637b256db73d3276ed9fb88abf47ffcb65a52d8fec90
```

Check it in PowerShell with `Get-FileHash .\LyricHub_1.3.1_x64-setup.exe -Algorithm SHA256`. It is also in `SHA256SUMS.txt`.

## Requirements

As in 1.3.0: Windows 11, 64-bit (tested), the Spotify desktop app or experimentally a browser, the Microsoft Edge WebView2 Runtime, and internet access for the lyrics lookup.
