# LyricHub 1.0.1

A small update to 1.0.0 (2026-10-27).

## What's new

- **Compact card for songs without lyrics.** If LRCLIB has no synced lyrics for a song, and for podcast episodes, the overlay shrinks to a small card with cover, title and artist. It stays at the side of its anchor and grows again with the next song that has lyrics. The Bar layout keeps its single row and only gets narrower.
- **AltGr works again while LyricHub runs.** AltGr reaches Windows as Ctrl+Alt, so AltGr+E (€ on a German keyboard) opened the edit mode and the € never arrived. Now LyricHub hands such a key back to the window in front whenever the right Alt key is held and the combination types a character in the active keyboard layout. Ctrl+Alt with the left Alt key still triggers the hotkeys.
- **More private diagnostics.** Logs, the Diagnostics page and self-test reports name the program in front (for example `Discord.exe`) instead of its window title, which could show chat servers or documents. The diagnostics export hides song titles, artists and albums, so it can go into a public bug report.
- LRCLIB requests identify LyricHub with a link to the repository.
- The settings window and the overlay run on SvelteKit 3, which fixes two low-severity SvelteKit advisories.

The full list is in the [changelog](https://github.com/HeiligerHoly/LyricHub/blob/v1.0.1/CHANGELOG.md).

## Requirements

- Windows 11, 64-bit (tested); Windows 10 from version 2004 is not tested
- The Spotify desktop app (Microsoft Store or spotify.com); the web player is not supported
- Microsoft Edge WebView2 Runtime: part of Windows 11; if it is missing, the installer fetches it
- Internet access for the lyrics lookup

## Installation

1. Download `LyricHub_1.0.1_x64-setup.exe` from the assets of this release and run it. You can install it over 1.0.0; settings, offsets and cached lyrics live in your user profile and stay.
2. The installer sets LyricHub up for the current user only and needs no administrator rights.
3. The installer is not code-signed, so Windows SmartScreen reports an unknown publisher. Choose "More info" → "Run anyway".

SHA-256 of `LyricHub_1.0.1_x64-setup.exe`:

```
fbe37d287f61ff7c6025d8cc40d2dc9ca1a192cbea7af537823a5641a9c7efe4
```

Check it in PowerShell with `Get-FileHash .\LyricHub_1.0.1_x64-setup.exe -Algorithm SHA256`.
