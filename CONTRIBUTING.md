# Contributing

Thanks for wanting to help. LyricHub is a one-person project, so reviews happen when there is time.

## Before you start

- **Bugs:** open an issue with the bug form.
- **Ideas:** open an issue with the idea form first, so we can agree on it before you write code.
- **Building, running and testing:** see [README.md](README.md), sections "Requirements for building", "Development" and "Tests and spikes".

## Rules

- **No song lyrics anywhere in the repository:** not in code, tests, fixtures, screenshots or logs. Tests use invented text.
- **Two languages:** every UI text exists in German (`src/lib/shared/locales/de.ts`, the reference) and English (`en.ts`).
- **Small pull requests:** one topic per pull request, with a note on how you tested it.
- **AI help is welcome:** LyricHub itself is vibe-coded. Run and test the change yourself before you open the pull request.
