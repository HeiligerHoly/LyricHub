# Security

LyricHub runs locally on your PC. It has no accounts and no telemetry. The only online service it talks to is [LRCLIB](https://lrclib.net), over HTTPS, to fetch lyrics. Settings, the lyrics cache and logs stay in `%APPDATA%\LyricHub`.

## Reporting a problem

Please report security problems privately: open the repository's **Security** tab and choose **Report a vulnerability**. Do not open a public issue for them. This is a one-person project, so an answer can take a few days.

## Supported versions

Only the latest release gets fixes.

## Lyrics and rights holders

The repository never contains song lyrics. LyricHub fetches them while it runs and keeps them only on the user's PC. If you are a rights holder and find lyrics in this repository, open an issue and they will be removed.
